# Calorie Compass Native iOS — Phase 2A

This directory contains the Phase 2A (native chat logger) working scaffold:
- Xcode project file (CalorieCompass.xcodeproj)
- SwiftUI bootstraps (App, ContentView, LogChatView)
- BackendService for API calls (POST /api/meal-assistant)

## Next steps for a developer:
1. Open CalorieCompass.xcodeproj in Xcode (macOS required)
2. Set up team/provisioning if needed
3. Use/expand LogChatView for native meal logging—wiring in backend as defined
4. Run app in Simulator or on device to test chat logger

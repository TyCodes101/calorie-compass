Use this tracker for issues found during archive, upload, App Store Connect processing, TestFlight install, and release-candidate internal QA. Do not invent issues or mark retests complete without real evidence.

## Severity Definitions

- `Blocker` — prevents archive/upload/processing/install, blocks first launch, causes critical data/privacy risk, or blocks core guest/auth/account lifecycle testing.
- `High` — blocks safe internal testing or a major core flow.
- `Medium` — should fix before external users or wider rollout.
- `Low` — polish, copy, documentation, or non-blocking cleanup.

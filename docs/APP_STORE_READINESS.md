# App Store Readiness (MacroMesh)

This is a lightweight checklist to ensure the iOS shell has the minimum UX + copy needed for App Store submission.

## Required UX/copy surfaces
- [ ] About MacroMesh (what it does)
- [ ] Nutrition disclaimer (not medical advice)
- [ ] Privacy/data explanation (guest vs signed-in)
- [ ] “Estimates can be wrong — review before saving” safety copy
- [ ] Data reset/deletion explanation (what happens, what is deleted)

## Product quality bars
- [ ] No dead-end screens
- [ ] Helpful loading/error/empty states across core flows
- [ ] Guest mode remains seamless
- [ ] Consistent MacroMeshTheme/AppCard styling across major screens

- This repo already contains deeper App Store/TestFlight execution docs (see `docs/app-store-readiness.md`, `docs/phase6*`).
